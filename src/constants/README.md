# Static Constants Directory

## Responsibility
Contains read-only application constants, settings, configuration maps, and static datasets. Prevents magic numbers and duplicate values.

## Examples
- `weatherCodes.ts`: Complete mapping of WMO weather codes to human-readable names and weather severity tiers.
- `defaultChecklist.ts`: Starter emergency checklist categories (e.g. food, water, light, documents) and items.
- `languages.ts`: Configuration list of supported languages (locales, display names, and language codes).
- `locations.ts`: Fallback/major cities coordinates mapping for immediate forecast availability.
