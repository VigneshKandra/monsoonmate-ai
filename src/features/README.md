# Feature-Sliced Components Directory

## Responsibility
Contains feature-specific business logic and complex component compositions. This encapsulates different functional requirements of the MonsoonMate AI app, keeping code cohesive and organized by feature.

## Features
- `/planner/`: Preparedness Plan form, AI recommendation results, plan downloader.
- `/weather/`: Live Weather widget, radar simulations, WMO code interpretations, severe weather alerts.
- `/checklist/`: Interactive emergency checklist, local storage syncing, Gemini checklist recommender.
- `/travel/`: Safety-aware route advisor and travel warning reports.
