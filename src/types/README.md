# TypeScript Types Directory

## Responsibility
Contains common, reusable TypeScript type definitions, interfaces, and enums used across the application. Ensures type safety and consistent contracts.

## Examples
- `weather.ts`: Interfaces mapping the Open-Meteo response structure, daily/hourly forecasts, and weather alert schema.
- `planner.ts`: Types representing user form input data and structured AI preparedness plan schemas.
- `checklist.ts`: Structures for interactive emergency checklist items (e.g. `id`, `label`, `category`, `checked`, `custom`).
- `travel.ts`: Typings for travel advisory requests (coordinates, transit type, origin/destination names) and report objects.
