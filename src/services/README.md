# API & External Services Directory

## Responsibility
Contains service abstractions for external data fetching, API clients, and network integrations. Isolates HTTP calls and mapping layers from the UI.

## Examples
- `weatherService.ts`: Interacts with the Open-Meteo API to fetch forecast and weather conditions.
- `geminiService.ts`: Formulates prompt templates and structures data queries passed to the Gemini API.
- `translationService.ts`: Facilitates translating interface context or AI outputs into targeted local languages.
