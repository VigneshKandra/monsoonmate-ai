# Utility Functions Directory

## Responsibility
Contains pure helper functions, calculations, and formatters that do not depend on React state or external APIs.

## Examples
- `weatherHelpers.ts`: Helper to convert WMO codes (e.g. 95, 96, 99) into human-readable severity descriptions (e.g. "Severe Thunderstorm") and tailwind color schemes.
- `formatters.ts`: Helper functions to format dates, times, temperatures, and wind speeds.
- `exportHelpers.ts`: Generates a downloadable PDF or Text version of the AI-generated preparedness plan.
