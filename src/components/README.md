# Global Components Directory

## Responsibility
Contains reusable, global UI components that are feature-agnostic. These components compose the overall page structure but do not contain business/feature logic.

## Examples
- `Navbar.tsx` / `Header.tsx`: Responsive navigation header.
- `Footer.tsx`: Branding and footer links.
- `ThemeToggle.tsx`: Dark/Light theme mode switch.
- `LanguageSelector.tsx`: Component to change locale/interface language.
