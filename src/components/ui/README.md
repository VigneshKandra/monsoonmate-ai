# Primitive UI Components Directory

## Responsibility
Contains low-level, atomic design system components (typically managed or imported via shadcn/ui). These components are style-centric, highly flexible, and generic (no business logic).

## Examples
- `button.tsx`
- `card.tsx`
- `input.tsx`
- `alert.tsx`
- `badge.tsx`
- `dialog.tsx`
- `progress.tsx`
